# Telegram Weather Bot 🌤️

Этот бот позволяет пользователю выбрать страну и город и получить текущую погоду с помощью API OpenWeather.

## 🧠 Возможности

- Поддержка стран и городов (настраивается)
- Интерактивные кнопки выбора
- Получение данных о погоде из OpenWeather API
