#  Weather Telegram Bot

Простой и полезный Telegram-бот для отображения актуальной погоды по запросу пользователя.  
Работает с OpenWeather API, умеет показывать температуру, влажность, скорость ветра и многое другое.

## 🚀 Возможности

- Получение текущей погоды по городу
- Поддержка нескольких языков
- Интерактивное меню
- Кнопки управления
- Подключение к OpenWeather API
- Удобный и понятный интерфейс

## 🛠️ Технологии

- Python
- python-telegram-bot
- requests
- dotenv
